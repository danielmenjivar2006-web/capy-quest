# CAPY QUEST — Word Kingdom

Juego educativo de inglés con nouns, verbs, adjectives, lectura y escritura.

Para instalarlo en Android, abre el sitio de GitHub Pages en Chrome y elige Instalar aplicación en el menú.

Para activar el sitio: Settings → Pages → Deploy from a branch → main → /(root) → Save.

El progreso se guarda localmente en cada dispositivo. No publiques datos personales de menores en este repositorio.
